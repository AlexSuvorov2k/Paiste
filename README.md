# Paiste Wiki

**Paiste Wiki** — это мобильное приложение для Android, предоставляющее подробную информацию о продуктах компании Paiste. Приложение предоставляет пользователям доступ к информации о сериях тарелок, их характеристиках, артистах и актуальным новостям бренда.

## Основные возможности

*   **Каталог тарелок:** Подробное описание серий, используемых сплавов, областей применения и характера звучания.
*   **Новости:** Интеграция с официальными источниками для получения последних новостей Paiste.
*   **Поддержка и обучение:** Информация об анатомии тарелок, классификации звука и основах выбора палочек.
*   **Многоязычность:** Поддержка русского и английского языков.
*   **Уведомления:** Система оповещений о новых публикациях.
*   **Оффлайн доступ:** Использование локальной базы данных SQLite для работы без интернета.

## Стек технологий

*   **Язык программирования:** Java, Kotlin.
*   **База данных:** Room Persistence Library (надстройка над SQLite).
*   **Сетевые запросы и парсинг:** Jsoup для извлечения данных из веб-ресурсов.
*   **Загрузка изображений:** Glide.
*   **Архитектура:** Многомодульная структура (app, core:database).
*   **Firebase:** Интеграция Firebase Analytics.
*   **UI:** Android X, Navigation Component, Fragments.

## Структура проекта

*   `:app` — основной модуль приложения (UI, фрагменты, активности).
*   `:core:database` — модуль для работы с базой данных (сущности, DAO, Room).
*   `assets/databases` — предустановленные базы данных на разных языках.
